# Условие
Разработать программу на языке C, которая считывает с клавиатуры строку с пробелами с помощью функции fgets(), находит в ней САМОЕ ДЛИННОЕ СЛОВО и выводит его на экран.
# Алгоритм и блок схема
1. Начало работы. Настройка русской локали для корректного отображения кириллицы в консоли.
2. Ввод строки. С помощью функции fgets() считывается строка s целиком вместе с пробелами, после чего функцией strcspn() удаляется символ переноса строки \n.
3. Инициализация переменных. Переменным максимальной длины слова (m), позиции его начала (p), текущей длины слова (c) и индекса (i) присваиваются нулевые значения.
4. Посимвольный обход строки в цикле:
	• Если текущий символ s[i] является разделителем (пробелом, знаком препинания) или концом строки ('\0'), проверяется условие c > m. Если оно истинно, обновляются значения m = c и p = i - c. Затем счетчик текущего слова сбрасывается (c = 0).
	• Если достигнут конец строки (s[i] == '0'), цикл прерывается (break).
	• Если символ является частью слова, длина текущего слова увеличивается на единицу (c++).
5. Вывод результата. Проверяется условие m > 0:
	• Если слово найдено, в цикле от p до p + m - 1 посимвольно печатается самое длинное слово и его длина m.
	• Если слов в строке нет, выводится соответствующее сообщение.
6. Конец работы.
